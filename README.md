# Youtube_Transcript
End-to-End YouTube Video Transcribe Summarizer LLM App

Overview

This project showcases an AI-powered application that integrates Google Gemini Pro to transcribe and generate concise summaries of YouTube videos. It enhances accessibility and content review efficiency by allowing users to extract key insights from videos effortlessly.

Features

YouTube Video Transcription: Extracts accurate transcriptions using Google Gemini Pro.

AI-Powered Summarization: Generates concise summaries with adjustable length and language settings.

User-Friendly Interface: Enables easy video upload, transcription, and summary retrieval.

Multi-Language Support: Provides summaries in multiple languages for diverse user needs.

Tech Stack

Programming Language: Python

Libraries: OpenAI API, YouTube API, Flask, Streamlit

Cloud Services: Google Gemini Pro, Google Cloud Storage

Version Control: Git, GitHub
